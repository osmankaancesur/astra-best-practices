# Changelog

All notable changes to this project are documented here.

## [1.2] - 2026-09-18

### Added

- Root-level guidance for diagnosing persistent instructions that cause pauses, confirmation requests, unfinished handoffs, or divergence from the user's intended outcome.
- Explicit instruction-provenance guidance in `references/instruction-design.md`.

### Changed

- Expanded the instruction-priority guidance in `references/astra-guidance.md` to cover confirmation requests and unfinished handoffs.
- Added instruction-conflict diagnosis to the audit checklist in `SKILL.md`.
- Refreshed source provenance against the listed official sources on 2026-09-18.

## [1.1] - 2026-09-13

### Added

- Initial `astra-best-practices` skill.
- Outcome-focused completion guidance.
- Contextual document loading and progressive disclosure.
- Safe autonomy and permission-boundary guidance.
- Selective subagent/delegation guidance.
- Risk-calibrated testing and verification.
- Guidance for auditing Astra prompts, skills, and `AGENTS.md`.
- Official source map and refresh rules.
